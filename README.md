# Useful AGENTS.md

This is a simple AGENTS.md template for my useful agents.<br/>
Installs common `RULES.md` to each agents rule directory.

Currently `Claude Code`, `Codex`, `Antigrativy` is supported.

## Get Started

1. Clone this repository on your local environment
   ```bash
   yong@ubuntu-server ~/ :$ git clone https://github.com/yymin1022/UsefulAGENTS.md.git
   ```
3. Install with automated script
   ```bash
   yong@ubuntu-server ~/ :$ cd UsefulAGENTS.md
   yong@ubuntu-server ~/UsefulAGENTS.md/ :$ ./install.sh
   ```
